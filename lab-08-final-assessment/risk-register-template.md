## Column guide

| Column | What to write |
| --- | --- |
| **ID** | A short unique ID. Keep it stable, people will refer to it. |
| **Risk** | What could happen, in one sentence. Not the finding, the consequence. |
| **Severity** | Critical / High / Medium / Low. Use the audit's severity. |
| **Evidence** | The check ID, the file and line, or the audit report name. |
| **Fix** | The concrete change that closes it. |
| **Owner** | The person or team accountable for the fix. |
| **Due date** | The date the fix is due; include it for deferred work. |
| **Status** | Open / In progress / Fixed / Accepted / Deferred. |

## Status rules

- **Fixed** means the change is made and the audit confirms it.
- **Accepted** means you decided not to fix it. Write down who decided and why.
- **Deferred** means it has a date. Write the date down.
